## Summary
This course project explores the relationship between a country’s economic wealth and the success of its professional men's tennis players, as measured through the Association of Tennis Professionals (ATP) rankings and common player performance metrics. The motivation for this analysis stems from the observation and mutual understanding that professional tennis is a resource-intensive sport, requiring large financial investments in training, coaching, travel, and competition over the course of a few years to several decades. As a result, players from wealthier countries may have certain structural advantages that contribute to higher performance outcomes in matchplay. This project seeks to determine whether such advantages are observable and significant in real-world data and whether macroeconomic indicators such as GDP can help explain some of the variation in ATP rankings.

The central research question that is guiding this project is: *"Is there a relationship between a country’s wealth, measured by GDP, and the likelihood of producing top-ranked ATP players?"* To address this question, we integrated three complementary datasets from a variety of creadible sources: an ATP players dataset containing demographics and physical characteristics, an ATP rankings dataset capturing player performance over time, and a country-level macroeconomic dataset providing GDP and other related indicators and statistics. By combining these three datasets, we were able to link individual player performance with national economic conditions, which would serve as the basis for the rest of our insight.

The analysis began with extensive data preprocessing to ensure consistency and usability across datasets. This included converting improperly formatted date fields, appropriately handling NaN/missing values, standardizing country identifiers, and removing irrelevant or inconsistent entries such as obsolete countries or aggregated regions. Once cleaned, the datasets were merged using player IDs and country-level mappings, resulting in a dataset that was suitable for further analysis.

Exploratory data analysis revealed that both GDP and player performance metrics were highly skewed. Since this was not ideal for us to move forward with, log transformations were utilized to better visualize relationships. Various visualizations, such as scatter plots, box plots, and aggregated country-level comparisons, were used to examine patterns and trends in the data. These analyses indicated a weak but positive relationship between GDP and player performance. To our understanding, this suggested that while wealthier countries tend to produce stronger players on average, the relationship is not strong or deterministic and cannot be directly associated with causation.

To further investigate this relationship, we implemented a linear regression model to predict player ranking outcomes based on both player characteristics and economic indicators such as GDP. The model demonstrated somewhat limited predictive power, indicating that GDP and the available player features alone are insufficient to accurately predict rankings. This suggests that tennis performance is influenced by a much broader set of factors not captured in the datasets we examined to support answering our research question. These could include, but are not limited to, coaching quality, habitual training enviroment and resources, and individual talent.

Overall, this project highlights both the notable potential and the cautionary limitations of integrating data to study sports performance. While economic wealth has an effect, it is only a small piece of a much more complex system that requires further analysis over time.

## Data Profile
This project utilizes three primary datasets that together provide a diverse perspective on professional tennis performance, combining individual player attributes, match outcomes, and country-level economic indicators. The integration of these datasets allows for a thorough analysis that links micro-level athlete characteristics with macro-level economic conditions.

The first dataset, the ATP Players Dataset from Jeff Sackmann (atp_players.csv), contains 65,989 rows and 8 columns and serves as the foundational dataset for player-level demographics and physical attributes. Each row represents a unique player and is identified by a player_id, which acts as a key for linking across datasets. The dataset includes variables such as first and last name, dominant hand (e.g. left, right, ambidextrous, or unknown), date of birth, country code (IOC format), and height in centimeters. One notable characteristic of this dataset is that it spans several decades of professional tennis history. This wide coverage introduces both strengths and challenges worth nothing. While it provides a rich pool of player information, it also includes outdated or incomplete records, particularly for historical or less popular players where attributes such as height or handedness may be missing. Additionally, the date of birth field is stored in a non-standard numeric format, requiring transformation before it can be used for our analysis. This aside, the dataset is useful because it provides the variables necessary to explore how individual player characteristics may relate to performance outcomes over an extended period of time.

The second dataset is also from Jeff Sackmann. This ATP Rankings Dataset (atp_rankings_current.csv), contains 92,341 rows and 4 columns and captures weekly ranking updates for players during the 2024 tennis calender year. Each record includes a ranking date, player rank, player ID, and ATP ranking points, which are accumulated based on performance in ATP Challenger, ATP 250, ATP 500, Masters 1000, and Grand Slam tournaments. Unlike the players dataset, this dataset has a time-series structure, meaning that each player can appear multiple times across different weeks. This allows for a hollistic view of player performance over time. The use of the 2024 season specifically was a deliberate choice to ensure that the analysis reflects a current competitive landscape of professional tennis, rather than being influenced by historical changes in the sport. However, this also introduces limitations, as rankings represent discrete snapshots rather than continuous performance and may not fully capture fluctuations between ranking periods. The rankings dataset is essential because it provides the primary outcome variables, rank and points, that serve as quantitative measures of overall player success in professional tennis.

The third dataset, the USDA International Macroeconomic Dataset, is publicaly provided by the USDA. It introduces a macroeconomic dimension to the analysis by providing country-level indicators, most notably Real GDP in U.S. dollars. This dataset spans from approximately 1970 to 2035, and includes both historical observations and forward-looking projections. It contains data for a large array of countries, across the globe, covering nearly all nations represented in men's professional tennis and the ATP dataset. The inclusion of GDP allows us to best estimate a country’s overall economic capacity, which can be interpreted as a proxy for resources available for athletes. However, the dataset also includes aggregated regional entries (such as “Asia Less Japan”) and projected values, both of which introduce potential inconsistencies in analytical conclusion-making. These entries were removed or handled carefully to ensure alignment with player-level data. Additionally, because GDP is measured at the country level, it represents an average or aggregate condition rather than the specific circumstances of individual tennis players.

The integration of these datasets required linking across two different types of identifiers. The ATP players and rankings datasets were merged using the player_id, which provides a direct and reliable connection between player attributes and performance metrics. However, linking the tennis data to the GDP dataset required a more complex approach, as it involved mapping three-letter IOC country codes to full country names used in the macroeconomic dataset. This mapping step was crucial for ensuring that each player was correctly associated with the appropriate economic data for their country of representation.

From a storage and organization perspective, all datasets are maintained within the project repository in a structured directory format. This organization ensures that the original data remains unchanged while allowing cleaned and transformed versions to be used for analysis. It also supports reproducibility by supporting full data transparency.

In terms of ethical and legal considerations, the ATP datasets are distributed under a Creative Commons Attribution-NonCommercial-ShareAlike license, which permits their use for academic and/or research purposes but restricts commercial applications. As mentioned previously, the USDA macroeconomic dataset is publicly available and falls within the public domain, making it freely usable for all people. Importantly, none of the datasets contain sensitive personal information beyond publicly known athlete attributes, minimizing privacy concerns. However, an important analytical limitation arises from the combination of individual-level and country-level data, which introduces the potential for ecological bias. While GDP can provide insight into national-level trends, it does not directly represent individual players.

These combined datasets enable us to explore whether a country’s economic strength acts as a “multiplier” for the development and success of its tennis players, while also highlighting the complexities and limitations in combining data across levels of aggregation.

## Data Quality
The data quality assessment was a key component of this project, as the reliability and validity of any analysis depend heavily on the integrity and transparency of the underlying data. Across the three datasets used in this project, we identified several categories of data quality issues, including missing values, inconsistent formatting, mismatched identifiers, skewed distributions, outdated or invalid entries, and structural differences between datasets. Each of these issues required careful evaluation to determine how they could impact analysis and interpretation.

One of the most prevalent issues observed was missing values. In the ATP players dataset, key attributes such as height and handedness were incomplete for a subset of players, particularly those who were active in earlier periods or were less well-documented. While these variables were not the primary focus of the research question, they still contributed to our exploratory analysis and modeling. Missing values in these columns could reduce statistical power or introduce bias if certain types of players were systematically underrepresented. In the GDP dataset, missing values appeared for certain countries and years, often in cases where economic data was unavailable or not reported. This posed a more significant concern, as GDP was a central variable in the analysis. Overall, the presence and distribution of missing values required careful consideration to ensure that conclusions were not unintentionally skewed.

Another major data quality issue involved inconsistent data formats. For example, the date of birth (DOB) field in the ATP players dataset was stored as a floating-point number rather than a properly formatted date. Values such as “19900101.0” are not directly interpretable for temporal analysis and complicate the calculation of derived variables such as age. Similarly, the ranking date field in the rankings dataset required standardization to support time-based comparisons and alignment with other variables. These inconsistencies reflect a broader challenge in real-world data, where datasets collected from different sources often lack uniform formatting standards.

A particularly challenging issue arose from inconsistencies in country identifiers across datasets. The ATP players dataset used three-letter IOC country codes, while the GDP dataset used full country names. This mismatch created a barrier to integration, as there was no direct correspondence between unique identifiers. In addition, some countries were represented differently across datasets due to variations in naming conventions, abbreviations, or historical changes. Without addressing this, these inconsistencies would prevent efficient linkage between player data and economic indicators.

Another important data quality concern was the presence of outdated or invalid entries. The players dataset included records for countries that no longer exist, such as Yugoslavia and the Soviet Union. These entries are not compatible with modern GDP data and therefore introduce inconsistencies when attempting to align datasets. Similarly, the GDP dataset contained aggregated regional entries, such as “Asia less Japan” or “Asia and Oceania,” which do not correspond to individual tennis player nationalities. These inconsistencies in representation create challenges in maintaining a consistent level of analysis across datasets.

Skewness in the data distributions was another significant issue we encountered. Both GDP and player ranking points exhibited highly skewed distributions, with a small number of countries or players having disproportionately large values. This type of distribution can distort data, making it difficult to identify meaningful patterns or trends. In raw visualizations, most data points were compressed into a narrow range, while a few extreme values dominated the scale. This characteristic of the data required careful handling during analysis to ensure accurate interpretation.

Another issue stemmed from differences in data granularity between datasets. The ATP players and rankings datasets operate at the individual level, capturing detailed information about each player, while the GDP dataset is aggregated at the country level. This mismatch introduces the risk of ecological fallacy, where conclusions about individual outcomes are inferred from aggregate data. While this does not invalidate the analysis, it places important potential limitations on how results can be interpreted.

Finally, the provenance of the data also influenced its overall quality. The ATP dataset was compiled by Jeff Sackmann from multiple sources rather than being sourced directly from an official ATP database. Although widely used and generally reliable, this aggregation process introduces the possibility of minor inconsistencies or gaps. Similarly, the GDP dataset includes both observed and projected values, which may differ in accuracy. Understanding these origins was important for evaluating the reliability of the data and interpreting results appropriately.

In summary, the data quality assessment revealed a range of issues typical of real-world datasets, including missing values, inconsistent formats, identifier mismatches, skewed distributions, outdated entries, and differences in granularity. Identifying these issues was essential for understanding the limitations of the data and guiding the subsequent cleaning and integration process.


## Data Cleaning
The data cleaning process was designed to transform the three separate datasets into a unified dataset suitable for analysis. Because the datasets differed in format, granularity, and conventions, cleaning involved a series of operations, each addressing a specific issue identified during the data quality assessment. All steps were implemented using Python, primarily with the pandas library, and were scripted to ensure reproducibility and transparency.

The first major task involved standardizing data types. One key example was the date of birth (dob) column in the ATP players dataset, which was originally stored as a floating-point number (e.g., 19900101.0). To make this usable for analysis, values were first converted from floats to integers to remove the decimal component, then cast to strings, and finally parsed into datetime objects. This transformation enabled the calculation of player age, which became an important  metric used throughout the analysis. Without this step, it would not have been possible to align player characteristics with ranking dates in a meaningful way.

Similarly, the ranking date column from the ATP rankings dataset was converted into a standardized datetime format. This ensured consistency across datasets and allowed us to extract the year component for alignment with GDP data. With both birth dates and ranking dates in compatible formats, we were able to calculate player age at the time of each ranking observation.

To address inconsistencies in country identifiers, we constructed a custom mapping dictionary to translate three-letter IOC country codes (e.g., “USA,” “ESP”) into the full country names used in the GDP dataset (e.g., “United States,” “Spain”). This mapping step was important for enabling integration across datasets and required careful validation to ensure accuracy. By standardizing country identifiers, we established a consistent key for linking player-level and country-level data.

We also performed filtering operations to remove entries that could not be reliably integrated. Aggregated regional categories in the GDP dataset were removed because they do not correspond to individual player nationalities. In addition, historical country entities such as Yugoslavia (YUG) and the Soviet Union (URS) were excluded from the players dataset, since they do not have corresponding entries in the modern GDP dataset. These steps ensured consistency and prevented invalid merges.

Once the datasets were standardized and filtered, we proceeded with integration. The ATP players dataset was first merged with the ATP rankings dataset using the player_id field as a key. This one-to-many merge preserved all ranking records while attaching player attributes. The resulting dataset was then merged with the GDP dataset using the standardized country identifiers. In both cases, left joins were used to retain all player records while incorporating additional information where available.

Following integration, we addressed remaining missing values. For categorical variables, such as handedness, missing values were imputed with the label “UNKNOWN” to preserve real observations. For critical numerical variables, such as GDP and ranking points, rows with missing values were removed to maintain analytical integrity. This approach balanced the need to retain data with the need to ensure reliability in key variables.

More transformations were applied to prepare the dataset for analysis. GDP values were structured in a way that allowed for log transformation to address skewness, and in some cases were categorized into quartiles to support comparative visualizations. These steps helped make the data more interpretable and suitable for identifying patterns that proved useful for guiding our research question.

Throughout the cleaning process, attention was given to resolving technical issues such as pandas DtypeWarning. By explicitly casting columns and validating conversions, we ensured consistency across the dataset. All transformations were documented within the codebase, with clear explanations of each step to support reproducibility.

Overall, the data cleaning process systematically addressed issues related to formatting, missing values, identifier mismatches, and structural inconsistencies. The result was a coherent and well-structured dataset that supports reliable integration, analysis, and modeling, while maintaining full transparency expectations.

## Findings
Our analysis revealed a clear positive relationship between a country's economic wealth and the success of its professional male tennis players. However, the strength of this relationship varied depending on how it was measured and visualized. When examining the relationship between GDP and player performance using a log-scaled scatter plot, we observed a distinct upward trend, indicating that players from wealthier countries tend to accumulate higher ranking points on average. Our use of a logarithmic scale reduced the extreme skewness present in raw GDP values and allowed underlying patterns to become more visible. Without this transformation, the majority of observations were compressed into a narrow range, making it difficult to interpret any meaningful relationship to answer our research question.

Further supporting this trend, categorical analysis using box plots grouped countries into GDP quartiles (Low, Mid-Low, Mid-High, and High). These visualizations demonstrated that players from countries in the “High” GDP group consistently exhibited higher median ranking points compared to those in the “Low” group. The interquartile range for higher-GDP countries tended to be wider, suggesting not only stronger average performance but also greater variability and the presence of more extreme outliers. However, despite these differences, there was still substantial overlap between groups, indicating that high GDP does not necessarily guarantee high performance.

We also analyzed the distributions of player ranking points and GDP independently and found that both variables were heavily right-skewed. A small number of players held extremely high point totals, and a small number of countries dominated global GDP. This observation justified the use of transformations and careful interpretation of averages, as traditional summary statistics could be misleading with this skewness. Log transformations and categorical binning allowed for more balanced comparisons and improved the clarity of our visualizations.

At a more aggregated level, we explored the relationship between GDP and average player points per country. This approach reduced individual-level noise and revealed a slightly stronger positive trend, suggesting that wealthier countries tend to produce stronger players overall. However, even at this level, the relationship was not perfectly linear, reinforcing our assunption and understanding that GDP is only one of many contributing factors.

Our predictive modeling using linear regression further illustrated this point. While GDP, along with player attributes such as age and height, contributed to explaining variation in ranking outcomes, the model’s overall explanatory power was limited. The relatively low R² value indicated that much of the variance in player performance remains unexplained by the variables included in the model. This suggests that while national economic status is a meaningful factor, it is not sufficient on its own to accurately predict player success.

Overall, the findings suggest that GDP functions as a contextual or enabling factor rather than a deterministic one. Wealthier countries may provide better infrastructure, training opportunities, and access to competition, which increases the likelihood of producing high-performing players. However, the high degree of variance observed across all analyses indicates that many other unobserved factors continue to play critical roles in determining player success. All visualizations, model outputs, and intermediate results have been saved within the project repository to ensure full transparency and reproducibility of these conclusions.

## Future Work
There are several lessons learned and opportunities for future expansion that we deemed necessary to clarify. One of the most important insights was the complexity involved in integrating datasets with different levels of granularity. Combining individual player data with country-level economic indicators required careful mapping and introduced the risk of bias where aggregate trends may not accurately reflect individual experiences. Future work could address this limitation by incorporating more granular economic data, such as regional or city-level indicators, which may better capture the environments in which players' talents are developed.

One promising direction for further analysis would be the inclusion of additional contextual variables that more directly reflect the resources available to players. For example, incorporating a variable such as “tournaments offered”—the number of professional tournaments hosted within a country—could provide insight into whether local access to competition influences player success. Countries that host more events may offer certain platers more opportunities to participate in tournaments, which could contribute to higher rankings over time.

Another valuable extension would be to examine economic conditions during a player’s developmental years rather than relying solely on current GDP. By linking GDP data to the period when players were between the ages of five and fifteen, future analyses could explore whether early-life exposure and access to economic resources has a stronger influence on long-term success. This would require aligning historical GDP data with player birth years and could provide a more meaningful perspective on the relationship between wealth and performance.

Additional environmental and structural factors could also be explored. For instance, climate and weather conditions may affect training consistency and access to facilities, particularly in countries with extreme seasonal variation or lack thereof. Similarly, incorporating data on court surface availability (hard, clay, grass) could provide insight into how training environments influence performance on different tournament surfaces. Travel-related factors, such as distance to major tournaments or frequency of international travel, could also be considered. These factors may have an influence on player performance on certain occassion, which could be worth looking into.

Expanding the dataset to include more detailed performance metrics would further enhance the analysis for future usage. For example, integrating match-level data, win-loss records, or other tournament profiling statistics could provide a more focused measure of player ability that is not solely based on ATP ranking points. Including data on coaches (whether they played professionally or not and how successful they were), national tennis academies in an area (quality training from high school age), or funding programs could also help explain why some countries outperform others with similar GDP levels.

Overall, future work has the potential to significantly deepen the analysis by incorporating thorough data, more sophisticated methods, and improved alignment between variables, ultimately providing a more comprehensive understanding of the many factors that influence success in men's professional tennis.

## Challenges
The most significant challenge we encountered in this project was the complexity of integrating datasets with different structures, formats, and identifiers. The process of linking GDP data with tennis data required reconciling over 200 country entities that were represented using different naming conventions and coding systems. Creating a custom mapping dictionary to translate between IOC country codes and full country names required careful verification and refinement. Even small inconsistencies or errors in naming could result in failed merges or incorrect matches, making this step both time-consuming and critical to the overall success of the project.

Feature engineering presented another major challenge. The date of birth column in the ATP players dataset was stored in a non-standard float format, which required multiple transformation steps before we could use it for our analysis. Converting these values into a usable datetime format involved careful handling to avoid data loss or misinterpretation. Ensuring that this transformation was accurate and consistent across all records was non-negotiable, as errors in age calculation could affect results and impact overall trasparency.

Handling skewed data distributions also proved to be a significant obstacle. Both GDP and player ranking points exhibited extreme skewness, which made it difficult to generate meaningful visualizations and statistical summaries using raw values. This required the application of log transformations and the creation of categorical bins to produce interpretable results. Deciding how to appropriately transform and present this data required both technical judgment team efforts and iterative experimentation to ensure that patterns were not exaggerated or biased.

Another challenge involved maintaining consistent data granularity across datasets. The need to remove aggregated regional entries from the GDP dataset and exclude obsolete countries from the players dataset was necessary to ensure alignment, but it also required careful filtering and validation. These steps added complexity to our workflow, but were necessary to ensure we were working with high-quality data.

Ensuring reproducibility of the entire workflow was also nontrivial. Many of the cleaning and integration steps, particularly those involving mapping and filtering, required multiple iterations and debugging by both of us. Managing missing values that emerged after merging datasets was especially challenging, as we had to make decisions together about whether or not to remove data without compromising analytical integrity. Translating these decisions into clean, well-documented, and executable scripts required careful organization.

Finally, interpreting the results posed its own set of challenges. The presence of high variability and the limitations of the available data made it difficult to draw strong causal conclusions. Balancing the desire to identify meaningful patterns with the need to avoid overinterpretation required a cautious and critical approach throughout the analysis.

These challenges highlight the complexity of working with real-world data and underscore the importance of careful data curation, validation, and documentation in producing reliable and reproducible results.

## Reproducing
This project was designed with reproducibility as a core objective, and the entire workflow from raw data to final results can be re-executed using the provided scripts and workflow automation. All data files, scripts, and outputs are organized within the repository to ensure that another user can replicate the analysis with minimal setup and little to no troubleshooting maneuvers.

To reproduce the results, a user should first clone the project repository from GitHub and navigate to the project directory. All required Python dependencies are listed in the requirements.txt file. These can be installed using:

`pip install -r requirements.txt`

Once dependencies are installed, the full data processing and analysis pipeline can be executed using the Snakemake workflow included in the repository. Snakemake was used to automate the sequence of steps from data cleaning and integration to analysis and visualization, ensuring that each step is executed in the correct order and that intermediate outputs are properly generated.

To run the full workflow, the following command can be used:

python -m snakemake --cores 1

This command will automatically execute all steps in the pipeline, including data preprocessing, dataset integration, feature engineering, and generation of visualizations and analysis outputs. The workflow is defined such that each step depends on the outputs of previous steps, ensuring consistency and preventing redundant computation.

The pipeline includes scripts for:

Cleaning and preprocessing the ATP players dataset and GDP dataset
Standardizing formats such as dates and country identifiers
Merging datasets using player IDs and country mappings
Generating derived variables such as player age
Producing visualizations such as scatter plots, box plots, and distributions
Running regression analysis and saving model outputs

All intermediate and final outputs are saved in designated folders within the repository (e.g., /data/processed/, /outputs/, /figures/), making it easy to verify results at each stage of the workflow.

Because all transformations are scripted and no manual steps are required after setup, running the workflow should produce identical results to those presented in the report. This ensures full reproducibility and transparency of the data curation and analysis process.
